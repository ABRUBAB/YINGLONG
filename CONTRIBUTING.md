# Contributing to YINGLONG

These rules are hard. CI enforces them (`node scripts/check-rules.mjs --history` and gitleaks); run
`git config core.hooksPath .githooks` once so the same checks run before every commit.

1. **English only.** No Chinese characters anywhere in the tree (U+3000-303F, U+3400-4DBF, U+4E00-9FFF, U+FF00-FFEF). Chinese-script data lives only in private HuggingFace datasets referenced by id, revision and SHA-256 in `docs/third_party.md`.
2. **No secrets in the tree.** Keys, tokens and mnemonics live outside the repository. Use environment variables or the loaders in `packages/sdk` that read key files at runtime.
3. **Amounts are integers in base units.** No floats for money anywhere (Solidity, TypeScript, Python).
4. **Never hand-write evidence.** Hashes, numbers and results in the documents are generated by `scripts/finalize` (`apps/agent/scripts/finalize.ts`) from JSON produced by the code. If a number is not generated, it does not appear.
5. **Honest labels.** Test units, simulators and testnets are always labelled as such. Never claim a bank partnership, a licence, e-CNY integration, an audit or production readiness.
6. **Deterministic code decides; AI only proposes, explains or escalates.** An AI signal may raise a tier (T1 to T2, T2 to ask). It never lowers a tier and never refuses on its own; only deterministic rules produce T4.

Layout and architecture: [docs/TECHNICAL.md](docs/TECHNICAL.md) and the [README](README.md). Security issues: [SECURITY.md](SECURITY.md).
